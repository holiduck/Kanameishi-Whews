# Kanameishi-Whews（要石-WHEWS）

> **本项目是 [要石 kanameishi](https://github.com/Lipomoea/kanameishi) 的非官方二次开发（fork）。**  
> 上游作者：[Lipomoea / リッポミャ](https://github.com/Lipomoea/kanameishi)。  
> 本仓库在上游基础上改为默认对接 **WHEWS API**（`api.beecld.com` / `api.2v8.cn`）等改动，**与官方要石无关**，请勿向上游反馈本 fork 的问题。

## 简介

Kanameishi-Whews 基于 Vite + Vue3 + Leaflet，提供地震预警与地震信息可视化；可用 Tauri 构建 Windows / macOS / Linux 客户端。

本 fork 仍遵循上游的 **AGPL-3.0** 许可：分发或通过网络提供本软件时，须按 AGPL 提供对应源代码。
